# Argus
> The Hundred-Eye Giant, the Guardian of Io.

The orverarching goal of this project is to create an information management system focus on the access control and authorization of data.
Aside from role-based basic controls (RBAC style model), Argus can further provide ABAC style document redactions for finegrain access control.
